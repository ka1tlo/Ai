# NEXORA AI — Web Alpha

Мобильная веб-версия, которую можно открыть в Chrome после публикации на хостинге.

## Что работает
- AI Reply: генерирует короткий естественный ответ на комментарий.
- AI Slides: создаёт структуру слайдов и идеи визуалов.
- Настройки API: собственный ключ можно сохранить в браузере; либо задать серверный `OPENAI_API_KEY`.

## Что пока не реализовано
- AI Slides пока генерирует текстовую структуру и промпты, но не создаёт готовые изображения и PDF/видео.
- AI Edit пока проверяет выбранные файлы. Автоматический анализ референса, монтаж и экспорт MP4 не подключены.
- Это alpha-проект, не production-сервис.

## Запуск локально
Нужен Node.js 18+.
1. Распакуй архив.
2. Открой терминал в папке проекта.
3. Выполни `npm install`.
4. Скопируй `.env.example` в `.env` и добавь `OPENAI_API_KEY` (или введи ключ в настройках сайта).
5. Выполни `npm start`.
6. Открой `http://localhost:3000`.

## Публикация, чтобы открывать сайт в Chrome на Android
Самый простой вариант — Render:
1. Создай репозиторий на GitHub и загрузи туда файлы проекта.
2. На Render создай новый **Web Service** и подключи репозиторий.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. В Environment добавь `OPENAI_API_KEY` (если используешь серверный ключ).
6. После публикации Render выдаст публичный HTTPS-адрес. Его можно открыть в Chrome на телефоне.

Не публикуй свой API-ключ в GitHub и не передавай его посторонним. Для публичного сервиса лучше использовать серверный ключ и добавить авторизацию/лимиты до того, как давать ссылку другим людям.
